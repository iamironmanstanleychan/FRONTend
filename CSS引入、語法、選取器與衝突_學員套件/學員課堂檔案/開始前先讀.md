# 開始前先讀

完整解壓學員套件，先開啟「學員入口.html」。

平日接續自己的作品；需要乾淨起點時，把所需開始版另複製到可寫位置，再用 VS Code 的 File > Open Folder 開該開始版資料夾，從 index.html 啟動 Live Server。保留自己的原作品及小變化。

小示範可獨立開啟，用來比較本節概念；只把需要的改動加入自己的網站。
