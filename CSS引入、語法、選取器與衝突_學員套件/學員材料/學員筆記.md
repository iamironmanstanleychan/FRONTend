# CSS 引入、語法、選取器與衝突

本節接續自己的網站，逐部分完成操作並保存修改。需要乾淨起點時，另複製相應開始版，保留原作品。

參考時數：4 小時。課堂茶餐廳為虛構教學案例；正式個案使用自己的選題、資料及設計。

## 使用本章檔案

下載學員套件後完整解壓，開啟「學員入口.html」。課堂檔案集中在「學員課堂檔案」；外層資料夾可改名，內部結構保持完整。

用 VS Code 的 File > Open Folder 開啟自己的網站根資料夾，即包含 `index.html` 的那一層；由該頁啟動 Live Server。以下 `css/site.css` 等檔案路徑均從正在編輯的網站根資料夾出發；CSS 中的 `url(...)` 則以 CSS 檔位置為起點。

下方連結開啟相應開始版或獨立小示範；平日仍接續自己的作品。

## 1. 讓五頁共用一份CSS

功能編號：`U01-T03-C01-01_共用樣式`。

[本片開始版](<../學員課堂檔案/U01-T03-C01-01_共用樣式/開始版/index.html>) · [獨立小示範](<../學員課堂檔案/U01-T03-C01-01_共用樣式/小示範/index.html>)

### 觀察與操作

開啟「共用樣式」小示範，依次指出 inline、internal 和 external 的來源；在 DevTools 暫時取消 external 的 color，再恢復。回到五頁網站，對照每個 head 的 link。

### 概念與符號

CSS負責顯示層，HTML仍負責內容結構。CSS規則先寫選取器，再用大括號包宣告。color是屬性，冒號後是值，分號結束一項宣告。/* ... */是CSS註解。

inline寫在style屬性，只影響單一元素；internal放在head內的style，適合小示範；external放在獨立.css檔，由link載入，適合多頁共同樣式。本課主站使用css/site.css，五頁都加入相同link，改一份便影響五頁。CSS副檔名不可誤存為HTML。

h1, h2的逗號表示兩組選取器共用規則；.brand選HTML中class="brand"的元素。HTML的class值不加句點，句點只寫在CSS選取器中。這片先改善文字色及焦點，不同時加入版面技術。

### 加入自己的專案

1. 在根目錄新增css資料夾，內建site.css，輸入下列完整CSS。
2. 在五個介紹頁的head內各加入`<link rel="stylesheet" href="css/site.css">`。
3. 儲存，依序查看五頁標題及文字色；用Tab選到連結確認焦點框。
4. 小示範比較style屬性、style元素與外部檔，主站只保留外部檔。

## 2. 選中需要改變的元素

功能編號：`U01-T03-C01-02_選取器與範圍`。

[本片開始版](<../學員課堂檔案/U01-T03-C01-02_選取器與範圍/開始版/index.html>) · [獨立小示範](<../學員課堂檔案/U01-T03-C01-02_選取器與範圍/小示範/index.html>)

### 觀察與操作

用 Elements 展開 nav → ul → li → a；在小示範把 nav a 暫改 nav > a，觀察匹配消失後恢復。再指出同一元素上的兩個 class。

### 概念與符號

元素選取器如p選所有同類元素；class以句點開頭，適合重用；id以#開頭，指定頁內唯一元素。空格表示後代，例如nav a會找到nav內更深層的a；>只選直接子元素，nav > ul能選我們導覽中的ul，但nav > a選不到被li包住的連結。

.food-card.recommended沒有空格，表示同一元素同時有兩個class；.food-card .recommended有空格，則找卡片裡面的後代。屬性選取器a[aria-current="page"]依屬性值選目前頁面。:hover在指標移到元素時生效，:focus-visible在瀏覽器判定需顯示焦點時生效，鍵盤使用者也需要可見位置。

### 加入自己的專案

1. 將下列選取器加入site.css末尾。
2. 在menu.html第一個article加recommended class，其他class保留。
3. 查看只有第一張卡有邊框、目前頁面連結加粗。
4. Chrome右鍵檢查第一張卡，在Elements的Styles查看各條規則；小示範把空格與>互換觀察選取範圍。

## 3. 用DevTools找出實際採用的規則

功能編號：`U01-T03-C01-03_衝突與繼承`。

[本片開始版](<../學員課堂檔案/U01-T03-C01-03_衝突與繼承/開始版/index.html>) · [獨立小示範](<../學員課堂檔案/U01-T03-C01-03_衝突與繼承/小示範/index.html>)

### 觀察與操作

選取小示範的 p，打開 Styles 和 Computed。記下採用的 color，再對調兩條 .note，重新核對。完成後恢復原次序。

### 概念與符號

Cascade是瀏覽器決定同一屬性採用哪個值的規則。本片比較同一作者來源、沒有!important及cascade layer的普通宣告：先比較specificity，再比較出現次序。id通常高於class/屬性/偽類，後者高於元素；權重相同才由較後規則勝出。實際完整cascade還包括來源、重要性和層，不可背成「最後一行永遠贏」。

某些屬性如color和font-family會由父元素繼承，border、margin一般不會。元素有自己直接宣告的值時，不只拿父元素較具體的選取器競爭。DevTools的Styles可見被劃掉的宣告，Computed顯示最終值。不要靠不斷增加id或!important把問題藏起來。

### 加入自己的專案

1. 開啟小示範，查看 class="note" 的段落顏色。
2. Chrome按右鍵「檢查」，在Elements選該段，查看Styles中哪個color被劃掉。
3. 把兩條.note對調，重看同權重的順序結果。
4. 回主站在site.css末尾只加一條.brand { color: #08786c; }，確認效果後把舊.brand色值統一，避免重複衝突。
