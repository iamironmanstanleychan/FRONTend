# 陳記茶餐廳網站規劃

## 使用者任務
訪客先看食物與價格，再找營業時間；點餐只作前端模擬。

## 頁面地圖
- index.html：認識餐廳及入口
- about.html：閱讀餐廳故事
- menu.html：查看食物介紹
- location.html：查看餐廳地址與營業時間
- contact.html：練習查詢表單
- order.html：後續 React 模擬點餐

## 重複模式
每頁共用餐廳名稱、五頁導覽及教學聲明。
餐點以名稱、分類、價格表示。

## 算法
1. 打開食物介紹頁。
2. 選一款食品及數量。
3. 若數量小於1，提示修改數量並返回第2步；未修正前不進第4至6步。
4. 否則以每份價錢乘數量。
5. 顯示明細，讓訪客確認。
6. 顯示模擬送出提示。

## 完成條件
從首頁可找到食物介紹及位置。
每款食品都有名稱和價格。
模擬送出清楚說明沒有真實接單。

內部檔案採可搬移相對路徑，大小寫一致。
