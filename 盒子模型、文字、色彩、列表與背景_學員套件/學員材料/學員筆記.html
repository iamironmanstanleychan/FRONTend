使用本章檔案

下載學員套件後完整解壓，開啟「學員入口.html」。課堂檔案集中在「學員課堂檔案」；外層資料夾可改名，內部結構保持完整。

1. 分清內容、內距、邊框、外距

功能編號：U01-T03-C02-01_盒子與留白。

本片開始版 · 獨立小示範

觀察與操作

打開盒子小示範的 Computed 盒子圖，逐一指 content、padding、border、margin。切換 content-box／border-box，量度外框寬度。

概念與符號

盒子由內到外是content、padding、border、margin。content放文字或圖片，padding是內容到邊框的內距，border是邊界，margin是盒子外面與鄰居的距離。預設content-box的width只計內容，200px加左右20px內距及2px邊框，外框為244px；margin另算。

box-sizing:border-box讓width包含padding及border，同一設定外框仍200px。max-width設定上限；本例在可用寬度較小時可縮小，但內容少不會自動縮寬。1rem 相對根元素的字體大小，比固定一大堆像素容易保持比例。本片主站卡片仍依正常文檔流一張接一張，不先教Grid。

加入自己的專案

  1. 把盒子規則加入site.css末尾。
  2. 在menu.html右鍵檢查food-card，查看Computed的盒子模型，逐區指出內距及外距。
  3. 在小示範把box-sizing改content-box，先算244px再看實際；改border-box比對。
  4. 回主站只調整padding一次，確認文字與邊框距離變，並保存。

2. 讓段落和清單容易讀

功能編號：U01-T03-C02-02_文字與列表。

本片開始版 · 獨立小示範

觀察與操作

在小示範改 square／circle 及 outside／inside，觀察換行的標記位置。回主站放大頁面，檢視段落及導覽。

概念與符號

font-family指定字體候選，system-ui使用系統介面字體，sans-serif是最後備選。font-size控制大小，font-weight控制粗幼，line-height控制行距，text-align控制對齊。繁體中文長段落保留足夠行距和適當行長，不把字縮小來塞滿畫面。

color是文字顏色，background-color是背景。十六進位色碼如#08786c只是表示方式，也可見rgb或色名。資訊不能只靠顏色傳達，推薦卡還應有「推薦」文字。列表外觀可用list-style-type改square或none，但保留ul/li內容關係；padding-left留出符號位置。

加入自己的專案

  1. 把文字規則加入site.css。
  2. 為menu.html的第一款食品在名稱後加「（推薦）」文字。
  3. 在Chrome放大到200%，閱讀一段文字和全部導覽，確認仍可用。
  4. 小示範改list-style-type和list-style-position，觀察符號及換行；主站用square保持清楚。

3. 讓背景失敗時文字仍可讀

功能編號：U01-T03-C02-03_背景與路徑。

本片開始版 · 獨立小示範

觀察與操作

從 VS Code 檔案樹逐層指出 css/style.css 與 images/pattern.svg，修改 repeat、position、size 及 attachment 時每次只改一項。

概念與符號

background-image:url(...)的相對路徑從CSS檔位置開始。css/site.css找根層images需要../images/...，和HTML的src起點不同。background-color是圖片失敗時的底色，重要文字仍要在HTML。

background-repeat有repeat、repeat-x、repeat-y、no-repeat；position兩值說明水平與垂直位置；size可用cover填滿（可能裁切）或contain完整放入（可能留白）。attachment:scroll隨頁面內容捲動，fixed通常以視窗為基準，在部分裝置行為不同，要實際檢查。這些屬性在小示範逐一改，主站保留簡單底色以便閱讀。shorthand可合併，但初學先逐項寫清楚。

加入自己的專案

  1. 在獨立小示範開啟index.html，CSS位於css/style.css，圖片位於images/pattern.svg。
  2. 先將repeat-x改no-repeat，觀察只留一份；再改position為center top。
  3. 將size改cover和contain作比較，再把attachment由scroll改fixed並捲動。
  4. 回主站加入下列三條底色規則，確認即使沒有裝飾圖片文字也清楚。
