Web 檔案、路徑與有效 HTML 文檔｜課堂練習

各自完成以下操作。可翻閱 學員筆記 的完整骨架和兩頁程式。每次切換資料夾後，都確認 VS Code 檔案樹頂部是正在處理的作品。

練習一：首頁與自己的文字

位置：自己的正式練習根目錄 index.html。

  1. 找出文件宣告、根元素、文件設定及頁面內容，補齊缺少的部分。
  2. 讓分頁顯示「首頁｜陳記茶餐廳」，頁內主標題顯示「陳記茶餐廳」。
  3. 在 body 新增一段自己的營業特色，例如介紹早餐、午市或飲品。原有個人內容保留。
  4. 儲存後在瀏覽器重新查看：兩個標題位置清楚、段落出現、中文正常。
  5. 在自己的「文檔練習」副本，用 strong 標示一段文字中的重要內容，核對內層先結束、外層後結束。

完成後，向導師指出改 title 和改 h1 分別影響哪個位置。

練習二：多一個說明頁

位置：「路徑練習」根目錄下的 pages/help.html。

  1. 確認已有根目錄 index.html 和 pages/info.html，並能來回開啟。
  2. 把 pages/info.html 複製成同一層的 pages/help.html。
  3. 把新檔的 title 改為「使用說明」，h1 改為「使用說明頁」。保留返回上一層首頁的連結。
  4. 在根目錄 index.html 的 body 內另加一行：
<p><a href="pages/help.html">開啟使用說明</a></p>
  1. 儲存兩檔。由首頁按「開啟使用說明」，確認看到新標題，再按返回首頁。
  2. 用自己的話說明：為何首頁需要 pages/help.html，說明頁返回卻需要 ../index.html？

練習三：換位置後繼續用

關閉 Live Server，把整個「路徑練習」複製到另一個可寫位置，可自行改最外層資料夾名稱。從新位置 Open Folder、開啟 Live Server，由首頁分別進入兩個說明頁並返回。保留內部 pages 名稱和各檔相對位置。

返回正式練習，在 plan.md 留下相對路徑的使用原則；保留原本的規劃。最後保存三個作品資料夾，下一章開啟正式練習繼續。
