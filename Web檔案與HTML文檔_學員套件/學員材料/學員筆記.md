# Web 檔案、路徑與有效 HTML 文檔

本節會整理自己的首頁骨架，分辨分頁標題和頁內標題，再以兩個獨立網頁練習相對路徑。完成後，你可以指出每一部分的用途，並把整個作品資料夾搬到另一位置繼續使用。

## 先找到自己的檔案

沿用上一節的正式練習資料夾，一般名稱為 `chan-kee-practice`；如已改名，以你實際保存的資料夾為準。它應有自己的 `index.html` 和 `plan.md`。用 VS Code 的 **File → Open Folder** 開啟它；本節提到「正式練習根目錄」就是這一層。保留自己的首頁文字和網站規劃。

課堂套件中的「學員課堂檔案」提供操作說明。你的正式練習可以放在另一位置，最外層名稱亦可按需要更改；操作時以正在開啟的工作資料夾為起點。有檔案找不到時，請導師協助定位原作。

每次切換作品，先停止舊位置的 Live Server，再用 **Open Folder** 開啟正確資料夾，最後從新位置啟動 Live Server。看清楚檔案樹頂部的資料夾名稱，避免仍在預覽另一份同名檔案。

## 1. 網頁、網站與瀏覽器

網頁是瀏覽器可以呈現的一份文件；網站通常由一組相關網頁和資源組成。可以把網頁想成書中的一頁，把網站想成整本書。一本書有多頁，網站也可以有首頁、餐牌和聯絡頁；小型網站亦可以只有一頁。

Chrome 等瀏覽器負責讀取和呈現網頁。開啟網絡上的頁面時，瀏覽器向伺服器要求內容，接收 HTML 及相關資源，再組織成畫面。本節用 Live Server 從自己的電腦提供檔案；HTML 可以引用另外儲存的圖片、樣式和程式。

HTML 是 **HyperText Markup Language（超文本標記語言）**。「超文本」表示內容可透過連結互相連接；「標記」表示用標籤描述內容的用途。HTML 處理內容結構，CSS 處理外觀，JavaScript 處理互動。本節先把 HTML 結構寫清楚。

## 2. 標籤、元素與屬性

```html
<p>歡迎來到陳記茶餐廳。</p>
<html lang="zh-Hant">
```

第一行中，`<p>` 是開始標籤，`</p>` 是結束標籤，中間是內容，整組是一個段落元素。第二行是 `html` 的開始標籤：`lang` 是屬性名稱，`"zh-Hant"` 是值，用來表示主要語言為繁體中文。它不是一份完整網頁。

屬性寫在開始標籤內；本節統一以引號包住值，多個屬性用空格分隔。

## 3. 看懂一份完整的 HTML

以下是正式練習根目錄 `index.html` 的參考骨架。先與自己的檔案比較，補上缺少的部分；保留原有個人文字及 `plan.md`。

```html
<!doctype html>
<html lang="zh-Hant">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>首頁｜陳記茶餐廳</title>
</head>
<body>
  <h1>陳記茶餐廳</h1>
  <p>港式日常滋味，從一杯奶茶開始。</p>
  <p>課堂示範網站</p>
</body>
</html>
```

| 部分 | 用途 |
|---|---|
| `<!doctype html>` | 宣告使用現代 HTML 的標準模式 |
| `html` | 文件的根元素，包住 `head` 和 `body` |
| `lang="zh-Hant"` | 指明主要語言，協助讀屏及語言處理 |
| `head` | 放文件資料及設定 |
| `meta charset="utf-8"` | 宣告文字編碼；檔案亦要以 UTF-8 儲存 |
| `meta name="viewport"` | 設定手機等裝置的版面視窗寬度及初始縮放 |
| `title` | 文件標題，會出現在瀏覽器分頁等位置 |
| `body` | 放頁面的主要內容 |
| `h1`、`p` | 分別表示本頁主標題及一段文字 |

`lang` 不會把文字翻譯成中文，也不代替文字編碼。`viewport` 是後續響應式版面的基礎設定，實際排版仍要配合 CSS。

### 親自修改首頁

1. 核對自己的 `index.html` 只有一套 `html`、`head`、`body`，補齊上面的文件設定。本節練習完整寫出它們的開始及結束標籤。
2. 把 `title` 改為「首頁｜陳記茶餐廳」，儲存。從這個正式練習資料夾以 Live Server 開啟 `index.html`，看瀏覽器分頁。
3. 保留 `h1` 的「陳記茶餐廳」，在 `body` 內加入歡迎段落和「課堂示範網站」。若已有相同句子便保留，不重複加入；個人補充文字亦保留。
4. 確認分頁標題和頁內主標題各有自己的內容；中文清楚顯示。
5. 在 `body` 內再加一段自己的營業特色，儲存並重新查看。

### 元素的內外次序

```html
<p>本店的<strong>招牌奶茶</strong>即叫即沖。</p>
```

`strong` 表示內容的重要性。這裏它放在段落裏面，要先結束 `strong`，再結束外層 `p`。縮排方便閱讀，不能代替標籤。

另開一個自己的「文檔練習」資料夾，把目前的 `index.html` 複製進去，再在副本加入上述一段。以該資料夾為根開啟副本，核對字句和內外次序；正式練習保留原作。

`meta` 屬於 void element（空元素），不用也不能加 `</meta>`。本節統一寫 `<meta charset="utf-8">`。網頁能顯示，不代表原始標籤完全正確：瀏覽器有時會補足或修復結構，所以仍要回到 VS Code 核對。

## 4. 檔案位置與相對路徑

另建立「路徑練習」資料夾，與正式練習分開。用 **File → Open Folder** 開啟它；以下位置均以「路徑練習」為根：

```text
路徑練習/
├── index.html
└── pages/
    └── info.html
```

本節的 HTML 沒有另設網址基準。相對路徑從目前 HTML 所在資料夾出發：

| 寫在哪個檔案 | 連到哪裏 | `href` 的寫法 |
|---|---|---|
| `index.html` | 進入 `pages` 找說明頁 | `pages/info.html` |
| `pages/info.html` | 返回上一層找首頁 | `../index.html` |

連結使用 `<a href="目的位置">連結文字</a>`；本節只用它觀察位置，下一章再學連結的其他用法。`../` 表示上一層，路徑中的 `/` 分開每一層資料夾。

### 輸入兩個檔案

在「路徑練習」根目錄新增 `index.html`：

```html
<!doctype html>
<html lang="zh-Hant">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>路徑示範</title>
</head>
<body>
  <h1>根目錄首頁</h1>
  <p><a href="pages/info.html">開啟子資料夾說明頁</a></p>
</body>
</html>
```

新增 `pages` 資料夾，再在其內新增 `info.html`：

```html
<!doctype html>
<html lang="zh-Hant">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>子資料夾說明</title>
</head>
<body>
  <h1>說明頁</h1>
  <p><a href="../index.html">返回上一層首頁</a></p>
</body>
</html>
```

1. 儲存兩檔，從「路徑練習」以 Live Server 開啟根目錄的 `index.html`。
2. 按「開啟子資料夾說明頁」，再按「返回上一層首頁」。留意網址末段和 VS Code 的檔案樹。
3. 在 `pages/info.html` 暫時把 `../index.html` 改成 `index.html`，儲存，再從首頁進入說明頁並按返回。這時會尋找根目錄之下的 `pages/index.html`；該檔案並不存在。
4. 在 VS Code 恢復 `../index.html` 並儲存。若瀏覽器仍留在錯誤頁，先返回上一頁，或重新開啟根目錄首頁，再重新走兩個方向。

若路徑不正確，先找目前的 HTML，再按每一段路徑找目的檔案。檔名和路徑的大小寫必須一致；不能依賴某部電腦碰巧接受不同大小寫。

## 5. 搬移、保存及接續

同一作品的內部連結採相對路徑。搬移或改名時，把整個作品資料夾連同內部檔案帶走，保持它們的相對位置。只搬一個 HTML，或單獨改內層檔名，便可能需要修改連結。

1. 關閉「路徑練習」的 Live Server，把整個資料夾複製到另一個自己可寫的位置；可把最外層改名為「我的路徑練習」。
2. 用 **Open Folder** 開啟新副本，重新啟動 Live Server，再由首頁走到說明頁及返回。重新開啟可避免誤看舊位置。
3. 用 **Open Folder** 返回自己的正式練習；在 `plan.md` 末尾加入「內部檔案採可搬移相對路徑，大小寫一致。」。若已經有同樣意思的句子便保留。
4. 保存正式練習的 `index.html` 和 `plan.md`。下一章從它們接續；「文檔練習」及「路徑練習」另行保存。

完成前，自己指出 `head`、`body`、`title`、`h1` 和兩個連結的用途，再做 [課堂練習](<課堂練習.md>)。
