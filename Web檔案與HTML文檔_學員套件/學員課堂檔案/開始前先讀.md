# 本節的工作資料夾

先從你原來的保存位置，用VS Code的File → Open Folder開啟自己的正式練習，一般名為chan-kee-practice；如已改名，以實際位置為準。保留上一節的index.html、plan.md及個人內容。本節依學員筆記補首頁結構，最後在plan.md加上相對路徑原則。

「文檔練習」是首頁的個人副本，用來觀察巢狀元素；「路徑練習」由你另建index.html、pages/info.html，再延伸pages/help.html。各資料夾獨立保存，每次切換以Open Folder開啟正確根目錄；停止舊位置的Live Server後再從新位置啟動。

課堂資料從本包的學員入口.html開始閱讀。搬移時把整個套件或整個作品資料夾連同內部檔案帶走，保留內部結構；最外層可改名。不要把套件中的文件覆蓋自己的作品。
