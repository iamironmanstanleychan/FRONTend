## 準備自己的工作資料夾

1. 在 Finder 把導師提供的 `學員課堂檔案` 整個複製到指定位置，保留裡面的 `積木` 和 `我的第一個網頁`。
2. 在 VS Code 選 File > Open Folder，開啟剛複製的 `學員課堂檔案`。
3. 開啟 `我的第一個網頁/index.html`，按右鍵 > Open with Live Server，在 Chrome 看見「準備開始」。

以下操作路徑，都從 VS Code 開啟的這個資料夾開始。例如 `積木/H1_店舖招牌.html.txt` 是來源檔，`我的第一個網頁/index.html` 是自己的工作檔。

| 在哪裡操作 | 快捷鍵與動作 |
|---|---|
| 來源積木檔 | Command+A 全選 → Command+C 複製 |
| 工作檔 | 點標記下方的空白行 → Command+V 貼上 |
| 完成改動後 | Command+S 儲存 → Command+Tab 切到 Chrome |

Command 鍵也寫成 ⌘。回到工作檔後只點指定空白行，保留原有內容。貼錯時先用 Command+Z 撤回。

## H1：店舖招牌

來源：`積木/H1_店舖招牌.html.txt`。工作檔：`我的第一個網頁/index.html`。

複製來源檔全文，在工作檔「把積木 H1 貼在下一行」下面的空白行貼上並儲存。找到 `<h1>我的茶記</h1>`，只改中間的店名，保留兩邊標籤。儲存後看看招牌文字。

## H2：餐牌與訂單

來源：`積木/H2_餐牌與訂單.html.txt`。工作檔：`我的第一個網頁/index.html`。

複製全文，貼在 H2 標記下方並儲存。看看三款食品及訂單區。「加入」按鈕稍後接上 J1 才會更新數字。

HTML 負責內容和結構。可以改一款食品名稱；若改價錢，保留 `$` 和數字，例如 `$22`。

## C1、C2：外觀與排列

工作檔：`我的第一個網頁/style.css`。

1. 把 `積木/C1_主題與基本外觀.css.txt` 的全文貼在 C1 標記下方。
2. 把 `積木/C2_餐牌卡與訂單.css.txt` 的全文貼在 C2 標記下方。
3. 儲存，看看餐牌的排列及顏色。

在貼好的 C1 找到 `--brand: #08786c;`，可把色碼改成 `#a53f78`。保留冒號及分號，儲存後看看招牌。CSS 負責外觀和排列。

## J1：點餐互動

來源：`積木/J1_點餐互動.js.txt`。工作檔：`我的第一個網頁/script.js`。

複製全文，貼在 J1 標記下方並儲存。回到 Chrome 按食品的「加入」，看看名稱、總件數及總額。

JavaScript 負責互動及畫面更新。重新整理頁面會由 0 重新開始。

## 留下及保存自己的改動

改店名、一款食品名稱及一個主題色。每次只改一項，再儲存看看。可以向同學指出 HTML、CSS 和 JavaScript 各自負責的地方。

保留 `我的第一個網頁` 整個資料夾，包括 `index.html`、`style.css`、`script.js` 及 `images`。要搬到其他位置時，這些檔案一起搬，保留內部結構。本章稍後另建正式練習；體驗作品獨立保存，不用把已貼的程式帶入正式練習。

## 畫面跟不上時

先停手，向導師指出正在修改的檔案和畫面。導師會協助找回位置，或提供救援副本，保留你的原作品。

如果導師把接續資料夾命名為 `我的第一個網頁_接續`，之後就修改那裡的 `index.html`、`style.css` 和 `script.js`；來源仍在 `積木`。已包含的部分不用重貼，按導師指示接下一步，並保存正在使用的接續資料夾。


## 切換到正式練習

1. 儲存正在使用的體驗作品；按VS Code狀態列的埠號停止Live Server。
2. 在Finder找到自己的學員資料夾，在裡面新建空白 `chan-kee-practice`。不要改名或覆蓋體驗作品。
3. VS Code選 File > Open Folder，這次開啟 `chan-kee-practice`。Explorer根資料夾應顯示它，裡面暫時是空的。
4. 選 New File，命名為 `index.html`。從這一步開始，工作檔路徑都從正式練習資料夾起算。

## 親自輸入第一頁

輸入以下完整內容，再按Command+S。檔名要是 `index.html`，沒有額外的 `.txt`。

~~~html
<!doctype html>
<html lang="zh-Hant">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>陳記茶餐廳練習</title>
</head>
<body>
  <h1>陳記茶餐廳</h1>
  <p>歡迎來到我們的課堂網站。</p>
</body>
</html>
~~~

在Finder重新找到同一個檔案，確認它在自己的正式練習資料夾內。

## 預覽及修改

1. 在VS Code的 `index.html` 按右鍵，選 Open with Live Server。若開了Safari，把相同本機網址貼到Chrome。
2. 看見店名及歡迎語後，只把段落文字改成「本節我們建立第一個網頁。」。
3. Command+S儲存，再切到Chrome看看；需要時手動重新整理。
4. 在 `</body>` 前自行新增一句段落文字，儲存並預覽。

`h1`是頁內主標題，`p`是一段文字；文字放在開始和結束標籤之間。其餘HTML結構會在後續課題逐步解釋。

## 停止與重新開啟

按VS Code狀態列埠號停止Live Server，再重新整理舊網址。已顯示的畫面可能仍留着；回到 `index.html` 重新啟動服務，使用這次開啟的網址。

儲存檔案、停止服務，再選 File > Close Folder。從自己保存的位置重新開啟正式練習資料夾，找到 `index.html` 並啟動預覽。不要只依靠最近開啟清單或Chrome舊分頁。

## 留下兩份作品

保存體驗網頁及正式練習的整個資料夾。後續從你正在使用的正式練習接續，體驗網頁留下來作回顧。

找不到檔案或畫面未更新時，先向導師指出目前的資料夾、檔名及瀏覽器畫面。
