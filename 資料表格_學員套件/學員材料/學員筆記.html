本節重點

  • 行列及表頭

1. 資料表格

  • 同一組欄位
  • 每行一筆資料
  • 營業時間的對照

想像我們只看到一串 07:00、20:00，並不知道哪個是開店時間。表格用行和欄交代關係，讓訪客把日期、開店及關店對在一起。本節把位置頁的營業時間整理成資料表，稍後再練習合併儲存格。表格的用途是表達資料關係，網站版面排列會用 CSS。

操作：開啟自己的 location.html，找出營業時間的位置，先保存副本。

2. table、tr、th、td

  • table：整個表格
  • tr：一行
  • th 表頭、td 資料

試算表裏每一行有一組資料，HTML 也用 tr 表達一行。th 是標題儲存格，td 是一般資料儲存格。標題可能放在上方，也可能放在左邊，因此不能只把第一行全部當 th、其餘全部當 td 而不看意思。日期名稱在本例就是每行的表頭。

操作：在筆記中逐個指出一行的開始與結束，再數它有三個格。

3. caption 的表格名稱

  • 直接放在 table 內
  • 交代表格主題
  • 與欄標題分開

報表上面的「營業時間」讓人知道整份表在說甚麼，caption 就負責這個名稱。欄標題「日期」則只說明某一欄，兩者用途不同。把 caption 放在 table 裏，表格離開附近段落時仍有自己的名稱。本例的資料是虛構教學內容，要在名稱或附近文字清楚交代。

<table>
  <caption>營業時間（虛構示例）</caption>
</table>

操作：在 location.html 先建立 table 與 caption，再依序加入表頭和資料。

4. thead 與 tbody

  • thead：表頭區
  • tbody：主要資料
  • 每行對準相同欄位

一份報表的標題列跟資料列可以分區管理，thead 與 tbody 就表達這種結構。它們不會自動替你計算或補齊資料。這個表有日期、開店和關店三欄，每一行都必須對準。如果少了一個 td，後面的值便可能出現在錯誤位置，不應用空格或 br 補回。

操作：按筆記完整範例輸入三欄表，再從左至右讀出星期一至五的一整行。

5. scope 指出表頭方向

  • scope="col"：欄標題
  • scope="row"：行標題
  • 讀出資料與表頭的關係

查字典時要知道自己在哪一欄、哪一行。scope 指出表頭適用的方向，協助工具理解資料關係。上方的開店和關店用 col，左邊的星期名稱用 row。本節把關係寫清楚，即使畫面沒有格線，也仍然保留結構。複雜多層表頭可能需要其他方法，先把簡單表做好。

<tr><th scope="col">日期</th>
  <th scope="col">開店</th><th scope="col">關店</th></tr>
<tr><th scope="row">星期一至五</th>
  <td>07:00</td><td>20:00</td></tr>

操作：核對每個 th 的內容，再加對應的 scope。

6. 表格的外觀

  • 預設可能沒有格線
  • 資料關係仍然存在
  • 樣式在 CSS 章處理

如果你現在看不到像試算表的框線，先不要判定 HTML 失效。瀏覽器的預設表格本來可以很簡單。查看表頭、每行內容及資料位置，比只看外框重要。不要為了畫線而加入舊式 border、cellpadding 等版面屬性；之後會用 CSS 統一設定。

操作：由 Live Server 開啟位置頁，對照三欄文字，放大畫面閱讀。

7. 新增公眾假期一行

  • 新增一個 tr
  • 日期用 th scope="row"
  • 沿用 07:00 至 20:00

新增資料時，先複製一個完整 tr 的結構，再改成公眾假期。每行仍是日期、開店和關店，所以不要因文字長短而增減格數。完成後指着公眾假期的 20:00，能清楚說出它是該行的關店時間。這就是表格關係的用途。

操作：完成練習第 1 題，將新行放在 tbody 裏，儲存並重新載入。

8. tfoot 的摘要

  • 總結或表尾資訊
  • 保持欄位結構
  • 數字不會自動計算

試算表的最下方可能有合計或摘要，HTML 可以用 tfoot 表達這部分。可是 tfoot 不會替我們做運算，總額仍要自己提供或由程式計算。本例只放一段營業時間說明。若這段橫跨整行三欄，就要明確寫 colspan="3"。

<tfoot>
  <tr><td colspan="3">時間只作課堂示例。</td></tr>
</tfoot>

操作：在 tbody 後加入 tfoot，確認結束標籤仍在 table 內。

9. colspan 橫跨欄位

  • 一格佔多欄
  • 先數完整欄數
  • 同一行避免重疊

試算表的橫向合併，可以把一個格延伸到旁邊。colspan 也表示這個格佔多少欄，數字包含原來那一欄。三欄表的一個 colspan="3" 已經用滿整行，後面再加 td 就會多出一欄。先在紙上畫三格並圈出合併範圍，再看 HTML，比逐個試數字清楚。

操作：在自己的筆記畫三欄，核對表尾只需要一個橫跨三欄的 td。

10. rowspan 向下跨行

  • 下一行少寫已被佔用的格
  • 避免跨越列群組
  • 先畫格子再輸入

rowspan 讓同一格向下佔多行。假設早餐這個名稱要配兩款食品，第一行寫 rowspan="2"，下一行便不要再多寫早餐那一格，因為位置已經被佔用。合併應留在同一個 tbody 等列群組內。這一段使用獨立練習，避免把不需要合併的營業時間表變複雜。

操作：在獨立 table-practice.html 的 main 內輸入筆記的兩行早餐表；先用紙格對照每行位置。

11. 分組表頭的方向

  • colgroup 定義欄組
  • rowgroup 對應列群組
  • 合併保留可理解關係

有些報表會把兩個欄位合在同一個大標題下。這時不能只靠外觀猜關係，欄組要有 colgroup，合併表頭可用 scope="colgroup"；多行共用的表頭可配合 tbody 列群組使用 rowgroup。這些適合清楚的分組表格，過度複雜時應先考慮拆成幾個簡單表。

12. 四欄表的調整

  • 新增備註欄
  • 各資料行同步加格
  • 表尾 colspan 改為 4

如果想加一欄備註，不只改表頭便完成。每一筆資料都要提供對應格，表尾如果原本橫跨整行，也要改為四欄。請依次從 thead、tbody 到 tfoot 核對，保持每行的有效欄數一致。備註可以簡短，但不要靠少寫一個 td 來表示沒有內容。

操作：完成練習第 2 題，在四欄版本加入「備註」，並把表尾 colspan 改為 4。

13. 合併個人練習

  • 兩行早餐資料
  • 早餐表頭只寫一次
  • 畫出每格的範圍

現在各自完成兩行早餐的 rowspan 練習。第一行是早餐、奶茶、22，第二行是已被早餐表頭佔住的位置、菠蘿包、18。第二行的 HTML 因此只需寫食品和價錢兩個格。完成後用手指由左至右讀，確認没有食品跑到價錢欄。

操作：完成第 3 題，在同一 tbody 使用 rowspan="2" 的早餐表頭及兩筆食品資料。

14. 錯位的排查次序

  • 逐行數有效欄數
  • 檢查跨欄及跨行
  • 核對開關標籤

表格錯位時，先看哪一行開始偏移，再計算該行每個格佔多少欄。遇到 rowspan，要把上行已佔住的位置算進去。接着才查缺少的結束標籤。瀏覽器有時會修補錯誤結構，畫面沒有破裂也不代表原始碼正確。改完後再次讀出資料對應的表頭。

操作：在練習副本暫把 colspan 改错，觀察差異，再按紙格恢復。

15. 本節保存位置

  • 位置頁營業時間
  • 獨立合併練習
  • 清楚的表頭及資料

本節主站保留容易閱讀的營業時間表，額外合併練習保存在自己的練習資料夾。請自己指出一個 th、一個 td 及它們的關係，再解釋三欄改四欄時為甚麼表尾也要更改。下一章會在聯絡頁加入讓訪客輸入資料的表單。

操作：儲存位置頁及獨立練習，重新開啟一次；保留五頁導覽與其他素材。

表格實作參考

在 location.html 的 main 裏加入營業時間表，保留本來的導覽與位置說明：

<table>
  <caption>營業時間（虛構示例）</caption>
  <thead>
    <tr><th scope="col">日期</th><th scope="col">開店</th><th scope="col">關店</th></tr>
  </thead>
  <tbody>
    <tr><th scope="row">星期一至五</th><td>07:00</td><td>20:00</td></tr>
    <tr><th scope="row">星期六、日</th><td>07:00</td><td>20:00</td></tr>
  </tbody>
  <tfoot><tr><td colspan="3">時間只作課堂示例。</td></tr></tfoot>
</table>

另建 table-practice.html，使用完整骨架，把兩行早餐表放進 body。先畫出三欄和兩行再輸入：

<table>
  <caption>早餐食品（虛構示例）</caption>
  <thead><tr><th scope="col">時段</th><th scope="col">食品</th><th scope="col">價錢</th></tr></thead>
  <tbody>
    <tr><th scope="rowgroup" rowspan="2">早餐</th><td>港式奶茶</td><td>HK$22</td></tr>
    <tr><td>菠蘿包</td><td>HK$18</td></tr>
  </tbody>
</table>

分組表頭比較

閱讀這個兩層表頭，colgroup 的欄數與表頭覆蓋範圍對應：

<table>
  <caption>兩間示例分店的營業時間</caption>
  <colgroup span="1"></colgroup><colgroup span="2"></colgroup>
  <thead>
    <tr><th scope="col" rowspan="2">分店</th><th scope="colgroup" colspan="2">營業時間</th></tr>
    <tr><th scope="col">開店</th><th scope="col">關店</th></tr>
  </thead>
  <tbody><tr><th scope="row">示例分店甲</th><td>07:00</td><td>20:00</td></tr></tbody>
</table>
