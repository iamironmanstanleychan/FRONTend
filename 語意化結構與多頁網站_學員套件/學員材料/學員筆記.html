語意化結構與多頁網站

參考時數：8 小時。沿用自己的虛構茶餐廳教學網站，保留個人內容及修改。

開始位置

沿用自己的正式網站，先保存副本。以下網頁檔案路徑以該網站根資料夾為起點；外層資料夾可以使用自己的名稱。用 VS Code 的 File > Open Folder 開這個根資料夾，再從 index.html 啟動 Live Server。

新增獨立練習時，在自己的工作區另建同名練習資料夾，先使用下面的骨架。如果後面的完整 body 內容已包括 h1，請用它取代骨架中的示例 h1 及註解。較小的功能片段則加入指定位置，保留其餘原有內容。完成一小段便儲存並重新載入。

<!doctype html>
<html lang="zh-Hant">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>自己的練習</title>
</head>
<body>
<h1>練習主題</h1>
<!-- 把本節內容加在這裏 -->
</body>
</html>

本節重點

  • 語意元素與內容判斷
  • 五頁骨架與內容整理
  • 導覽與全域屬性
  • 個人練習及保存

1. 語意化結構與多頁網站

  • 五頁各有用途
  • 導覽次序一致
  • 元素說明內容角色

搬屋時，每個箱子都有標籤，才容易知道裏面放甚麼。網頁元素也可以表達內容用途。本節把首頁、簡介、食物、位置及聯絡分成五頁，讓訪客容易找到資訊。先整理內容角色，外觀仍保持瀏覽器基本樣式；CSS 章再處理排列與顏色。

操作：打開自己的網站及 plan.md。寫下五頁各自回答訪客哪一個問題，保留已完成的圖片與媒體。

2. head 與 header

  • head：文件資料
  • header：可見的介紹區
  • 頁面與文章都可有介紹區

head 放字元編碼、分頁標題等文件資料，header 則是 body 裏可見的介紹區。可以把網站 header 想成報紙的報頭，但文章自己的開頭也能有 header。它的意思由所在內容決定，並不保證永遠固定在畫面頂端。不要因名稱相似，把可見網站名稱放到 head 裏。

操作：把網站名稱與主要導覽放在 body 內的 header。核對 title 仍在 head。

3. nav 與主要導覽

  • 通往主要區域的連結
  • ul 表達一組項目
  • 連結名稱清楚

商場指示牌列出主要目的地，網站 nav 也把主要導覽組在一起。不是每個零散連結都要包 nav；例如圖片旁的來源連結可保留普通段落。主要導覽裏用 ul 列出五個入口，各頁使用相同名稱與次序，訪客換頁後便不用重新找路。

<nav aria-label="主要導覽">
  <ul>
    <li><a href="index.html">首頁</a></li>
    <li><a href="about.html">簡介</a></li>
  </ul>
</nav>

操作：在 header 中加入五項 nav。每個 a 放在自己的 li 中。

4. main 與本頁內容

  • 每頁一個可見 main
  • h1 清楚描述本頁
  • 共同導覽放在外面

報紙的報頭會重複，主要報道卻每版不同。main 放這頁主要、獨有的內容，重複的網站導覽與頁尾放在外面。本課每頁使用一個可見 main，並用一個清楚 h1 表達主題。這是本課容易維護的寫法，不要把「只有一個 h1」說成任何情況下都不能違反的 HTML 語法規則。

操作：把首頁現有介紹、圖片、媒體等主內容移入 main。移動整個完整區塊，保留標籤成對。

5. section 的主題

  • 一個有主題的分節
  • 通常配合標題
  • 依內容層次選 h2、h3

報告可以分成背景、目的和安排，每節都有自己的主題。section 也用來組織這類內容，通常會有標題。標題等級跟內容層次有關，不能只因 h3 字小便拿來當 h1。若只為之後排版而包住幾個元素，沒有獨立主題，div 仍然適用。

操作：在 about.html 的 main 內加入有 h2 的 section，保留 h1 作為整頁標題。

6. article 與 aside

  • article：可獨立理解的內容
  • aside：相關補充
  • 位置由 CSS 決定

把一段文章剪下來，仍然可以獨立理解，便適合考慮 article，例如有標題和內容的食品介紹。aside 是相關但屬補充的資料，例如食物背景小知識。aside 不會自動跑到右邊，article 也不會自動變成卡片。先按內容意思選，再在後面學排列。

操作：在 menu.html 為食品寫 article 及 h2；如加入食物小知識，判斷它適合一般段落還是 aside。

7. footer 與一般容器

  • footer：所屬區域的結尾資訊
  • div：一般分組
  • 按內容選元素

書本末頁可能放版權、聯絡及出版資料，網頁 footer 也常放這類結尾資訊。它可以屬於整頁，也可以屬於文章，並不會自動黏在螢幕底部。div 是沒有特別語意的一般容器，仍然有用途。我們無須把每個 div 都改成 section，也不用為了使用所有標籤而硬加內容。

操作：在五頁 main 之後加入相同簡短 footer，文字寫明課堂示範網站。

8. 五頁共用骨架

  • header、nav、main、footer
  • 每頁不同 title 及 h1
  • 保留原有內容

現在把剛才的角色組起來。先在首頁完成骨架，再把同一組導覽與頁尾帶到其他頁。複製後第一件事是改 title、h1 和主要內容，避免五頁都寫首頁。已有簡介頁就繼續編輯原檔，不需要以空白模板覆蓋。新增的 menu、location、contact 則各自建立完整 HTML 文件。

操作：按筆記的五頁內容表逐頁完成。每頁保存後立即由首頁連結開啟，再返回。

9. 五頁內容分工

  • 首頁：概覽
  • 簡介、食物：認識餐廳
  • 位置、聯絡：下一步資訊

首頁保留概覽及推薦，簡介解釋教學網站用途，食物頁集中介紹食品。位置頁放虛構地址、位置示意及稍後加入的營業時間；聯絡頁本節先放示例聯絡文字，表單在後續章節加入。頁數只是組織方式，真正要看每頁有沒有回答一個清楚問題。

操作：把首頁已完成的素材有選擇地放到相應頁面。圖片路徑仍以每份 HTML 所在位置起算。

10. 目前頁面的標記

  • aria-current="page"
  • 各頁標記自己的連結
  • 可見文字補充位置

商場地圖的「你在此」必須跟所在位置一致。aria-current="page" 告訴輔助工具哪個導覽項目是目前頁。它本身不保證變色，所以本節可在連結文字後加「（目前頁）」讓畫面也清楚。每頁只標自己的那一項；不能把首頁標記整段複製到五頁後忘記更改。

<a href="location.html" aria-current="page">
  位置（目前頁）
</a>

操作：在每頁對應的連結加 aria-current，並加可見目前頁文字。逐頁查看。

11. 五頁往返路線

  • 從首頁逐頁開啟
  • 從聯絡頁回到各頁
  • 核對網址及標題

只由首頁出發一次，可能漏掉其他頁的錯誤導覽。現在由聯絡頁前往食物、位置和簡介，再回首頁。每次看地址欄和 h1，確認連結真的到正確檔案。連結文字、href 和目前頁標記是不同部分，改位置頁標題不代表要把它的檔名一起改掉。

操作：完成個人練習第 2 題。把位置 h1 改為指定文字，檔名 location.html 保持。

12. id 與 class

  • id：頁內唯一識別
  • class：可重用分類
  • class 可列多個名稱

活動入場證有獨一的編號，也可以貼上同色分類貼紙。id 像編號，用來定位特定元素，頁內應唯一；class 像分類，多個元素可以共用，也可以用空格列出幾個類別。id 可配合頁內連結，class 之後可配合 CSS。單是加 class，不會自動產生外觀。

操作：在 about.html 學習用途 section 設 id="learning-purpose"，從首頁加 about.html#learning-purpose 連結。

13. style 與外觀設定

  • style 放 CSS 宣告
  • HTML 主題與外觀分工
  • 集中樣式在 CSS 章處理

連鎖店若每個招牌各自修改，日後較難保持一致。style 可以直接把 CSS 宣告寫在一個元素上，適合辨認語法，但大量重複會增加維護工作。本節只看一個例子，理解 color 是樣式屬性，並不改變段落的語意。正式網站的共同外觀留到 CSS 章集中處理。

<p style="color: darkgreen;">課堂示範網站</p>

14. title 屬性的提示

  • 可提供補充文字
  • 重要內容直接可見
  • 與 head 裏的 title 分開

電器旁的小貼紙可以補充提示，但重要操作不應只靠看得到貼紙的人才懂。title 屬性有時會以滑鼠提示顯示，觸控和鍵盤使用者未必能同樣取得。因此限制、用途及連結目的直接寫在可見文字裏。元素的 title 屬性，也與 head 內設定分頁名稱的 title 元素不同。

操作：在屬性練習頁比较可見說明與滑鼠提示。網站主導覽保持清楚的連結文字。

15. lang 的語言資訊

  • 整頁 lang="zh-Hant"
  • 其他語言可局部標示
  • 語言標記不會翻譯

一本書的封面標示語言，方便讀者和工具選擇適合的讀法。html 上的 lang="zh-Hant" 表示繁體中文；英文片段可以另外設 lang="en"。這是語言資訊，不會把文字自動翻譯，也不能代替正確文字編碼。五頁都要核對，而不是只在首頁設定。

<p>網站名稱：<span lang="en">Chan Kee</span></p>

操作：檢查五頁的 html 語言，並在簡介頁加入一小段英文示例。

16. time 與 mark

  • time：日期或時間
  • datetime：機器可讀值
  • mark：目前情境的相關內容

活動單張可以寫「十月八日」，time 的 datetime 再提供完整日期，讓內容更明確。mark 像閱讀時標出的相關位置，例如搜尋結果吻合的文字。它不是通用的重要程度標籤；要表達重要性仍要按內容考慮 strong。這些元素都先表達意思，顏色與樣式可以後續調整。

<p>更新：<time datetime="2026-10-08">
  2026 年 10 月 8 日
</time></p>

操作：在簡介頁加入示例更新日期；在獨立屬性練習以 mark 標示搜尋吻合詞。

17. 鍵盤焦點與 tabindex

  • 原生連結及按鈕已有焦點
  • 優先保留文件次序
  • 避免正數 tabindex 排序

使用 Tab 時，連結和按鈕本身已可取得焦點，通常不必再加 tabindex。0 可讓需要互動的元素進入正常次序，-1 通常供程式移動焦點，不會因此自動變成完整按鈕。正數會插入另一套順序，容易跟閱讀次序衝突。本節先保持正確 HTML 次序和原生元素。

操作：從首頁按 Tab 走過五個導覽連結，按 Enter 開啟目的地。若焦點次序奇怪，先核對原始碼排列及 tabindex。

18. hidden 的作用

  • 內容暫不呈現
  • 資料仍在 HTML
  • 顯示狀態不等於權限

有些內容只在特定情況才適用，hidden 可以先讓它不呈現。但檔案仍然包含這段文字，不能用來保護機密，也不等於刪除內容。要做按鈕切換顯示，還需要後續程式。隱藏區域中的表單控制也不能靠 hidden 保證不會提交；表單規則要另外處理。

操作：在獨立屬性練習頁加入 hidden 段落，保存、查看，再於編輯器移除 hidden，對照兩次畫面。

19. 簡介頁個人練習

  • 有 h2 的學習用途 section
  • 一段清楚內容
  • 主題放在 main 裏

現在完成簡介頁練習。先說清楚學習用途，再決定段落內容，最後用 section 和 h2 包起來。這段可以描述每次加入已學功能並保存自己的變化。完成後確認它位於 main，頁內 id 沒有重複，從首頁的片段連結也能找到這個位置。

操作：完成第 1 題及全域屬性練習；所有操作各自完成，導師按個別卡位提示。

20. 本節保存位置

  • 五個清楚主題
  • 一致的主要導覽
  • 語意與屬性互相配合

現在從自己的聯絡頁重新走一遍網站。訪客應能找到食品、位置及簡介，而每頁 title、h1 和目前頁標記彼此一致。語意元素幫助說明區域，全域屬性補充識別與語言。保存整個網站和自己的更改，下一章把營業時間整理成真正的資料表格。

操作：把未完成的頁面或卡位寫入 plan.md，保留最後能開啟的版本。
