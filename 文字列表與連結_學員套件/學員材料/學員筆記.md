# 文字、列表、連結與基本導覽

本節整理文字的層次、用列表表達內容關係，再把首頁和餐廳簡介連起來。完成後，你能選用合適的文字及列表元素，並沿着連結到達指定頁面或段落。

## 開始前先找對資料夾

從原來的保存位置，用 VS Code 的 File → Open Folder 開啟自己的正式練習，一般名為 `chan-kee-practice`；如已改名，以實際名稱為準。保留上一節的 `index.html`、`plan.md` 和個人內容。本節主線只補充首頁，並新增或補充 `about.html`。

另在你自己的可寫位置建立 `文字列表練習` 和 `連結練習` 兩個資料夾。每次轉換作品，以 Open Folder 開啟相應資料夾，停止舊位置的 Live Server，再從新位置啟動。這兩個練習與正式作品分開保存。

以下檔案位置都相對於正在操作的資料夾；搬移作品時，整個資料夾一起搬，保留裏面的層次。不要把新範例整頁覆蓋自己的正式作品。

## 一、文字有層次，也有用途

### 標題與段落

標題像報告的題目及分節：`h1` 表示本頁主題，`h2` 表示主要分節，`h3` 表示分節中的小題；層級可延續至 `h6`。按內容關係選用，不必用齊六級。本節每頁用一個清楚的 `h1`，其餘標題按層次安排。文字大小稍後可用 CSS 調整。

```html
<h1>陳記茶餐廳</h1>
<h2>食品介紹</h2>
<h3>主食</h3>
<p>供應熟悉的港式主食。</p>
<h3>飲品</h3>
<p>提供冷熱飲品。</p>
```

`p` 是一段完整意思。一般顯示方式下，原始碼中的 Enter 和連續空白不會原樣變成畫面換行；兩個不同意思可分成兩個 `p`。同一段中確有換行需要，例如地址，才用 `br`。不要用空白段落或一連串 `br` 推開版面。

```html
<p>歡迎光臨陳記茶餐廳。</p>
<p>課堂地址示例：<br>示範街 8 號<br>地下 A 舖</p>
```

本節把 `p` 的結束標籤寫清楚。不要把 `h2`、`ul` 或另一個 `p` 放進 `p`；瀏覽器可能提早結束該段。`br` 本身是空元素，沒有 `</br>`。

### 重要、語氣、引用與程式文字

| 元素 | 選用原因 |
|---|---|
| `strong` | 內容重要，例如重要提示 |
| `em` | 語氣上的強調 |
| `blockquote` | 獨立的一段引用，並用文字交代來源 |
| `code` | 程式片段或程式中的名稱 |
| `pre` | 保留文字的空格及換行，常與 `code` 配合 |

```html
<p><strong>課堂示範網站</strong>，內容只供練習。</p>
<p>請選擇<em>你需要的</em>資料。</p>
<blockquote><p>從一杯奶茶開始。</p></blockquote>
<p>引用來源：本節的示例宣傳句。</p>
<p>主標題使用 <code>h1</code>。</p>
<pre><code>&lt;h1&gt;陳記茶餐廳&lt;/h1&gt;</code></pre>
```

最後一行顯示程式文字，不會建立第二個主標題；`&lt;` 顯示小於號，`&gt;` 顯示大於號。`pre` 裏的 HTML 特殊字元仍需適當處理。

### 自己動手：建立文字練習

在 `文字列表練習` 建立 `index.html`，輸入以下骨架，再把上面的文字範例依次放入 `body`。儲存後用 Live Server 開啟。保留一個 `h1`，將示例宣傳句改成自己的句子，並在來源文字寫明是自訂句子。

```html
<!doctype html>
<html lang="zh-Hant">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>文字與列表練習</title>
</head>
<body>
</body>
</html>
```

## 二、選擇合適的列表

### 沒有必要先後次序：`ul` 與 `li`

購物清單中的項目通常可以調換位置而不影響意思。這類清單用 `ul`，每項放在一個 `li`。不要自行在項目前打圓點。

```html
<h2>本店特色</h2>
<ul>
  <li>港式主食</li>
  <li>冷熱飲品</li>
  <li>日常輕食</li>
</ul>
```

### 次序有意思：`ol` 與 `li`

步驟、排名等內容可用 `ol`。瀏覽器產生編號，不必在項目文字再打 `1.`、`2.`。

```html
<h2>了解餐廳的次序</h2>
<ol>
  <li>閱讀食物介紹</li>
  <li>查看位置及營業時間</li>
</ol>
```

需要接續前文編號時，可使用整數 `start`。下面從 5 開始，接着是 6；一般從第一步開始的流程毋須加入這個屬性。

```html
<ol start="5">
  <li>核對資料</li>
  <li>儲存文件</li>
</ol>
```

### 大類下面再分類：巢狀列表

把次列表放在所屬的 `li` 裏面，再結束這個 `li`。縮排方便人閱讀，真正決定關係的是標籤的位置。

```html
<ul>
  <li>飲品
    <ul>
      <li>熱奶茶</li>
      <li>凍檸茶</li>
    </ul>
  </li>
  <li>主食</li>
</ul>
```

### 名稱和解釋成對出現：`dl`、`dt`、`dd`

`dt` 寫名稱，`dd` 寫對應說明，整組放在 `dl`。像詞典的詞語與解釋，也可用於餐牌規則。同一名稱可以有多段說明。

```html
<dl>
  <dt>熱飲</dt>
  <dd>按餐牌基本價錢計算。</dd>
  <dt>凍飲</dt>
  <dd>適用飲品在基本價錢上加 HK$3。</dd>
</dl>
```

在 `文字列表練習/index.html` 的 `body` 結束前加入這些列表。把飲品次列表改成自己選的兩項，再說明為何它適合放在「飲品」裏面。額外試把 `start="5"` 改成 `start="0"`，觀察第一項編號，完成後改回 5。

## 三、補充自己的正式首頁

切回正式練習資料夾。保留 `index.html` 的完整骨架及自己的內容，只補缺少的項目：

1. 一個 `h1` 主題「陳記茶餐廳」，加上 `id="top"`。
2. 兩段簡介：「港式日常滋味，從一杯奶茶開始。」及「課堂示範網站」。
3. 本店特色的 `h2` 和 `ul`。
4. 了解餐廳次序的 `h2` 和 `ol`。
5. 熱飲／凍飲的 `dl` 說明。
6. 以下推薦食品，留待連結使用。

```html
<h2 id="food-intro">推薦食品</h2>
<ul>
  <li>乾炒牛河：HK$58</li>
  <li>港式奶茶：HK$22</li>
</ul>
```

已有同一內容就調整原位置，避免重複貼上。巢狀列表和編號變化保留在獨立練習。完成後，首頁應能分辨主題、主要段落及三類列表；`plan.md` 保留原有規劃。

## 四、把文字連到目的地

`a` 的內容是讀者看到的連結文字，`href` 是目的地。寫「閱讀餐廳簡介」比單寫「按此」清楚。

```html
<a href="about.html">閱讀餐廳簡介</a>
```

### 同一資料夾的頁面

正式練習內的結構：

```text
chan-kee-practice/
  index.html
  about.html
  plan.md
```

在正式練習新增 `about.html`。如果檔案已存在，先保留副本，在原檔補上簡介與返回連結，不要整頁覆寫。

```html
<!doctype html>
<html lang="zh-Hant">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>簡介｜陳記茶餐廳</title>
</head>
<body>
  <h1>餐廳簡介</h1>
  <p>陳記供應熟悉的港式餐點，陪伴街坊的日常。</p>
  <p><a href="index.html">返回首頁</a></p>
</body>
</html>
```

首頁 `body` 結束前加入以下連結。儲存兩個檔案，再由首頁前往簡介及返回首頁。

```html
<p><a href="about.html">閱讀餐廳簡介</a></p>
```

### 同一頁的指定位置

先在目標元素加上 `id`，再用 `#` 加該值。`id` 在同一頁內必須唯一，連結中的大小寫也要一致。本節用簡短英文字母及連字號，例如 `food-intro`。

```html
<p><a href="#food-intro">前往推薦食品</a></p>
<p><a href="#top">返回頁頂</a></p>
```

將這兩行放在首頁 `body` 結束前。短頁可能沒有明顯捲動畫面；可觀察網址是否加上 `#food-intro` 或 `#top`，並核對目標確實存在。

### 另一頁的指定位置

在 `about.html` 加入以下連結。「檔名」決定哪一頁，「# 後面的值」決定該頁的位置。

```html
<p><a href="index.html#food-intro">查看首頁推薦食品</a></p>
```

## 五、其他連結用途

以下在獨立的 `連結練習` 操作。先沿用本節的 HTML 骨架建立 `index.html`，將 `title` 和 `body` 內的 `h1` 設為「連結練習」，再把各例子放入 `body`。

### 外部網站及新分頁

外部網站使用完整網址。本地作品的頁面與檔案則使用相對路徑。

```html
<p><a href="https://developer.mozilla.org/zh-TW/docs/Web/HTML">閱讀 HTML 說明</a></p>
<p><a href="https://developer.mozilla.org/zh-TW/docs/Web/HTML"
      target="_blank" rel="noopener">HTML 說明（另開分頁）</a></p>
```

`target="_blank"` 請瀏覽器開啟新的瀏覽環境，通常是新分頁，也可能是新視窗；連結文字先告知讀者。`rel="noopener"` 明示不讓新頁透過 opener 存取來源頁。沒有需要時，維持一般同頁前往即可。

### 電郵及電話

`mailto:` 可交給已設定的電郵程式撰寫郵件，`tel:` 可交給支援通話的程式。它們不保證在每台電腦啟動相同程式，也不等於已寄信或撥通電話。本節只辨認寫法；以下是佔位範例，毋須加入作品或啟動。

```text
mailto:info@example.com
tel:+852XXXXXXXX
```

### 下載一個真正存在的檔案

在 `連結練習` 裏新增 `notes.txt`，以 UTF-8 儲存以下文字：

```text
陳記茶餐廳｜課堂示例
港式奶茶：HK$22
此檔案用來練習下載連結。
```

同一資料夾的 `index.html` 加入：

```html
<p><a href="notes.txt" download="餐廳資訊.txt">下載餐廳資訊（文字檔）</a></p>
```

`href` 指向真實來源 `notes.txt`；`download` 的值建議下載檔名。透過 Live Server 開啟頁面後按連結，查看下載結果並開啟檔案，核對剛才的三行內容。瀏覽器或伺服器設定可能影響行為；只寫 `download` 不會產生檔案，也不保證外部網站資源可以下載。

## 六、走完整條路線，再保存

回到正式作品，用 Tab 找到連結，再按 Enter 開啟；用 Shift + Tab 往回移動。保持瀏覽器原有的焦點提示，並確認每個連結文字可說明目的地。

- 首頁 → 餐廳簡介 → 首頁。
- 首頁 → 推薦食品 → 頁頂。
- 簡介 → 首頁推薦食品。

若路線不通，先核對檔案是否儲存、連結文字與引號、檔案名稱和大小寫、相對位置，以及 `id` 是否存在且唯一。不要用自己電腦的磁碟位置修補連結。

完成後保存三個作品資料夾。可複製整個正式練習資料夾、改外層名稱，再從新位置以 VS Code 開啟和啟動 Live Server，重走上述路線。成功後保留原作及新副本，清楚記下接續使用哪一個。

本節的內容對應學員筆記 v6 第 2.3、2.4 的核心主題；`id` 定位亦與 2.13 的相關部分相連。
