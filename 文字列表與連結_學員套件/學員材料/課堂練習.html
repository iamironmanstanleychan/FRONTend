文字、列表與連結｜課堂練習

各自完成以下工作，保留自己的文字。遇到問題時先儲存，向導師指出正在編輯的檔案及想前往的位置。

練習一：文字的層次

工作位置：文字列表練習/index.html。

  1. 為一間自訂餐廳安排一個主標題、兩個主要分節及其中一節的兩個小題。
  2. 寫兩段內容；在其中一段標示重要提示。
  3. 加入一段自訂宣傳句的引用，交代來源是自訂句子。
  4. 顯示一行 HTML 原始碼文字，畫面應看得到角括號。

向導師解釋你如何選擇 h2 和 h3，以及 Enter、p、br 的差別。

練習二：選擇與整理列表

工作位置：文字列表練習/index.html。

  1. 用合適的列表表示「三款可選飲品」及「查看餐廳資料的兩個步驟」。
  2. 在飲品一項裏加入兩款飲品的次列表；把次列表留在該項的 li 內。
  3. 加一組名稱與說明，解釋熱飲及凍飲價錢。
  4. 在另一個接續編號例子用 start="5"，再試 start="0"，觀察後改回 5。

回到正式 index.html，只在本店特色的 ul 裏增加一項「資訊清楚」，用 strong 標示這項文字。

練習三：讓兩頁互通

工作位置：正式練習的 index.html 和 about.html。

  1. 完成本節筆記的首頁及餐廳簡介。
  2. 從簡介頁增加一條前往 index.html#food-intro 的連結。
  3. 用鍵盤完成「首頁 → 簡介 → 首頁推薦食品」；再走首頁頁內及返回頁頂路線。
  4. 在自己的 plan.md 補充這兩頁各自負責甚麼，以及一條實際可用的相對路徑例子。已有相關段落便補充原段。

練習四：取得餐廳資訊檔

工作位置：連結練習/index.html 和 連結練習/notes.txt。

依筆記建立文字檔及下載連結。從 Live Server 的頁面下載並開啟檔案；對照來源的三行內容。把下載建議檔名改為你選的中性名稱，再查看結果。保留原 notes.txt，不要把 href 改成電腦的下載資料夾位置。

保存與回顧

保存正式作品與兩份獨立練習。複製整個正式作品，改最外層名稱後重新開啟，確認兩頁及頁內目的地仍然可到達。

在 plan.md 寫下一個你修正過的問題及修正方法；如沒有遇到問題，記下一條你會用來查找失效連結的方法。
