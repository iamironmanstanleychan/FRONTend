# 本節工作資料夾

用 VS Code 的 File → Open Folder 從自己的保存位置開啟正式練習，通常名為 chan-kee-practice；如已改名，以實際位置為準。保留 index.html、plan.md 及個人內容。本節補首頁，新增或補充 about.html。

另建「文字列表練習」及「連結練習」，每個都有自己的 index.html；連結練習依筆記新增 notes.txt。每次切換資料夾，停止舊位置的 Live Server，再從新位置啟動。

本套件從學員入口.html 開始閱讀。作品由你按筆記建立，請勿用閱讀文件覆蓋原作。搬移作品時整個資料夾一起搬，保持內部結構；最外層名稱可以更改。先以副本練習，保留原作，記下接續使用哪一份。
